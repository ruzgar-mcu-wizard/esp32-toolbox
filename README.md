# ESP32 Toolbox

A collection of Windows tools for ESP32 development.

## Projects

### ESP32-Flasher
GUI and console ESP32 firmware flashing tools.

### ESP-Tools-Studio
GUI and console frontend for Espressif esptool, espefuse, and espsecure.
Supports tool versions 4.12.0 and 5.5.0.

### exe-Builder
Build scripts and source files for compiling the applications.

## Contents
- Python source files
- Prebuilt Windows executables
- Build scripts
- Bundled Espressif utilities

## Platform
Windows
